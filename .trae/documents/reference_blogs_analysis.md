# 参考博客分析：baiwumm.com + blog.liushen.fun

## 一、两个博客的共同 DNA

| 特征 | baiwumm.com（谜叶象限）| blog.liushen.fun（清羽飞扬）|

| 技术栈 | Halo + 自定义主题 | Astro + 自研主题 |

| 功能丰富度 | 搜索/随机/足迹/动态面板 | 搜索/中控台/音乐/赞赏/流量 |

## 五、可借鉴清单（按优先级排序）

### 🥇 第一优先级：效果最好，实现简单

#### 1. 博客运行天数计数器（liushen）
- liushen 底部有「本站已苟活: 1652 天 01 时 22 分 02 秒」
- 已有"持续学习 N 天"的技术基础，直接加"博客运行 N 天"
- 实现：1段 JS，放在 footer partial

#### 2. 文章列表卡片加标签chip（liushen）
- 现在卡片只有分类，没有多标签
- liushen 每篇卡片下有一条 `#筑站手札 #Hexo #Astro` 的彩色标签行
- 实现：在 `b-article__body` 里加 `{{ range .Params.tags }}`

#### 3. 上一篇/下一篇导航（liushen）
- 文章底部灰色分割线 + 「← 上一篇」 「下一篇 →」
- Hugo 原生支持：`.PrevInSection` / `.NextInSection`
- 实现：在 `single.html` 文章模板加一行 partial

#### 4. 随机文章按钮（baiwumm）
- 顶部导航加一个 🎲 按钮，点击跳转随机文章
- 已有 Hugo `.Site.RegularPages` 数据，JS 几行搞定
- 实现：`b-nav` 里加一个链接，JS 监听点击

#### 5. 友情赞赏/支持按钮（liushen）
- 文章底部或侧栏加「赞赏」入口，放二维码或文字
- 实现：static 图片 + partial

### 🥈 第二优先级：效果好但需要更多改动

#### 6. 文章内阅读进度条（liushen）
- 文章详情页右侧栏有阅读进度条
- 实现：JS 监听 `window.scrollY`，计算百分比，填充一个 CSS 进度条

#### 7. 碎碎念区升级为"说说"（liushen+baiwumm）
- 当前是4条硬编码，改成 Hugo data 文件驱动
- 用 `data/moments.yaml` 存储，partial 循环渲染
- 可加时间戳、emoji

#### 8. 分类聚合卡片（baiwumm）
- 首页展示3个分类大卡片，每个带2-3篇子文章
- 实现：custom partial，遍历分类取前N篇

#### 9. 中控台/全站面板（liushen+baiwumm）
- 弹窗或滑出面板，聚合搜索+导航+统计
- 实现：JS + CSS，点击按钮弹出，背景半透明遮罩

### 🥉 第三优先级：需要后端或太大改造

#### 10. 评论系统前置展示
- 🔴 Hugo 静态站无后端 → 需要接 Giscus/Disqus 等第三方评论

#### 11. 阅读热度值/统计
- 🔴 需要统计后端 → 可用 Google Analytics API 但麻烦

#### 12. 音乐播放器
- 🟡 可行但可能干扰阅读体验

#### 13. CDN 流量展示
- 🔴 纯动态数据，静态站无法实现
