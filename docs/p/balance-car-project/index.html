项目概述

本项目旨在系统学习两轮自平衡小车（Two-Wheeled Self-Balancing Robot）背后涉及的控制理论。平衡车是一个经典的欠驱动、非线性、不稳定系统，是学习现代控制理论的绝佳实验平台。

本项目将从系统建模出发，逐步深入三种经典控制算法：

算法类型核心思想复杂度
PID经典控制不依赖模型，基于误差的比例-积分-微分反馈低
LQR现代控制基于状态空间的最优状态反馈控制中
MPC现代控制基于模型预测 + 滚动优化 + 约束处理高

平衡车系统简介

两轮自平衡车由以下核心部件组成：

  • 车身：绕轮轴可自由旋转的倒立摆
  • 两个独立驱动的轮子：提供前进/后退/转向力矩
  • 传感器：MPU6050（陀螺仪+加速度计）测量倾角和角速度
  • 主控：STM32 / Arduino 等微控制器
  • 执行器：直流减速电机 + 编码器

为什么平衡车是一个经典的控制问题？

  1. 不稳定性：车体天然是不稳定的倒立摆，不加控制瞬间倾倒
  2. 欠驱动：2 个电机需要同时控制 3 个自由度（倾角、位置、转向）
  3. 非线性：动力学方程包含三角函数项
  4. 多变量耦合：姿态角与速度之间存在强耦合关系
