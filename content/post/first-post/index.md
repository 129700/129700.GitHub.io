## 关于这个博客

这是我的个人主页，使用 [Hugo](https://gohugo.io/) + [Stack](https://github.com/CaiJimmy/hugo-theme-stack) 主题搭建。

在这里，我会记录：

- **技术学习笔记**：编程、嵌入式、算法等
- **项目记录**：从零到一搭建项目的完整过程
- **读书笔记**：阅读心得与思考

## 博客功能

- 左侧导航栏：Home / Archives / Search / Links
- 支持分类和标签
- 全文搜索
- 暗色模式切换
- 文章目录（TOC）

## 开始写作

```bash
# 创建新文章
hugo new content post/文章名称/index.md
```
