## 项目概述

本项目旨在系统学习两轮自平衡小车（Two-Wheeled Self-Balancing Robot）背后涉及的控制理论。平衡车是一个经典的**欠驱动、非线性、不稳定**系统，是学习现代控制理论的绝佳实验平台。

本项目将从系统建模出发，逐步深入三种经典控制算法：

| 算法 | 类型 | 核心思想 | 复杂度 |
|------|------|----------|--------|
| **PID** | 经典控制 | 不依赖模型，基于误差的比例-积分-微分反馈 | 低 |
| **LQR** | 现代控制 | 基于状态空间的最优状态反馈控制 | 中 |
| **MPC** | 现代控制 | 基于模型预测 + 滚动优化 + 约束处理 | 高 |

## 平衡车系统简介

两轮自平衡车由以下核心部件组成：

- **车身**：绕轮轴可自由旋转的倒立摆
- **两个独立驱动的轮子**：提供前进/后退/转向力矩
- **传感器**：MPU6050（陀螺仪+加速度计）测量倾角和角速度
- **主控**：STM32 / Arduino 等微控制器
- **执行器**：直流减速电机 + 编码器

### 为什么平衡车是一个经典的控制问题？

1. **不稳定性**：车体天然是不稳定的倒立摆，不加控制瞬间倾倒
2. **欠驱动**：2 个电机需要同时控制 3 个自由度（倾角、位置、转向）
3. **非线性**：动力学方程包含三角函数项
4. **多变量耦合**：姿态角与速度之间存在强耦合关系

## 三种控制算法对比

```
                ┌──────────────┐
                │  系统建模    │
                │ ─────────── │
                │ 状态空间方程  │
                └──────┬───────┘
                       │
       ┌───────┬───────┼───────┬───────┐
       ▼       ▼       ▼       ▼       ▼
   ┌──────┐┌──────┐┌──────┐┌──────┐
   │ PID  ││ LQR  ││ MPC  ││  ... │
   │      ││      ││      ││      │
   │无模型││状态  ││预测  ││      │
   │反馈  ││反馈  ││优化  ││      │
   └──────┘└──────┘└──────┘└──────┘
```

| 对比维度 | PID | LQR | MPC |
|----------|-----|-----|-----|
| 是否需要模型 | 不需要 | 需要线性化模型 | 需要精确模型 |
| 是否处理约束 | 不支持 | 不支持 | 支持 |
| 调参难度 | 经验试凑 | 权重矩阵 Q, R | 预测时域 + 权重 |
| 实时性 | 极高 | 高 | 中等 |
| 最优性 | 无保证 | 局部最优 | 有限时域最优 |
| 工程应用 | 最广泛 | 较多 | 日益增多 |

## 推荐学习路径

```
Week 1: 系统建模 → 牛顿力学推导动力学方程
Week 2: PID 控制 → 直立环 + 速度环 + 转向环
Week 3: LQR 控制 → 状态空间 → 求解 Riccati 方程
Week 4: MPC 控制 → 预测模型 → 滚动优化 → 仿真验证
```

> 控制理论之美，在于用数学的语言描述物理世界，再用算法驾驭它。
