## 关于友链

欢迎有相同兴趣的朋友与本博客交换友链，互相推荐优质资源。本博客主要关注：

- 🤖 **机器人** 与 **嵌入式开发**
- 🎛️ **控制理论** 与 **电机控制**
- 🚗 **RoboMaster** / **平衡车** 相关项目
- 📚 **技术学习笔记** 与 **知识分享**

## 推荐阅读

如果你刚开始接触这些领域，以下资源会很有帮助：

- **控制理论入门**：先从经典 PID 控制入手，理解比例、积分、微分的物理意义
- **嵌入式开发基础**：推荐从 STM32 系列开始，熟悉寄存器与 HAL 库两种开发方式
- **电机驱动实践**：直流减速电机、步进电机、舵机、无刷电机的控制方式各有特色
- **仿真与算法验证**：推荐使用 MATLAB/Simulink 或 Python 进行控制算法的先期仿真验证
